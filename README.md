
# Flight Price Prediction using Machine Learning

## Overview
This project predicts airline ticket prices using machine learning regression models.

## Dataset
Airlines Flight Price Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Best Model
Random Forest Regressor

Performance:
- R² Score: 0.9889
- MAE: 865.39
- RMSE: 2391.91
